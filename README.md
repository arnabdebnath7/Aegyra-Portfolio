### Architecture Highlights
- **Celestial Bolide (Meteor) Impact Preloader:** Real-time Three.js 3D trajectory, ember particle tail, and caldera shockwave awakening the valley.
- **2.5D WebGL Depth-Displacement Stage:** Custom GLSL vertex & fragment shaders with synchronized Z-depth maps, animated waterfalls, and GSAP ScrollTrigger camera choreography.
- **Invisible LSB Steganographic Watermark Engine:** Encodes `AEGYRA::SANCTUM::ARNAB-DEBNATH::GH-300543148::VERIFIED-ORIGIN::2026` into the Least Significant Bits of the RGB pixel channels so normal visitors see zero watermark while authorship is cryptographically verifiable in the built-in modal.
- **Strict `/figma-designer` & `/landing-page-design` System:** Two-layer CSS variables (`Core Colors` + `Color System` in Dark & Light modes), exact Tailwind scale named text styles (`Geist` & `Geist Mono`), concentric nested radii, and 25-variant interactive button matrix.
